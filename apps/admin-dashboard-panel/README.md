# Admin Dashboard Panel

## Overview
A complete admin dashboard with full CRUD operations, analytics, and data visualization. All data is stored in localStorage.

## Features
- ✅ Authentication (Login/Logout)
- ✅ Dashboard with KPIs and Charts
- ✅ Users Management (CRUD)
- ✅ Products Management (CRUD)
- ✅ Orders Management (CRUD)
- ✅ Analytics with Chart.js
- ✅ Dark/Light Theme Toggle
- ✅ LocalStorage Data Persistence
- ✅ Responsive Design
- ✅ Search & Filter
- ✅ Data Export (JSON)

## How to Use
1. Open `login.html`
2. Login with demo credentials
3. Explore all features:
   - View dashboard analytics
   - Manage users, products, and orders
   - Add, edit, or delete entries
   - Export data or clear and reload demo

## Data Storage
All data is stored in browser localStorage:
- `users` - User data
- `products` - Product inventory
- `orders` - Customer orders
- `loggedIn` - Auth status
- `theme` - Dark/light mode

**Note:** Clearing browser data will remove all information.

## Tech Stack
- HTML5, CSS3, JavaScript
- Chart.js for analytics
- Font Awesome icons
- LocalStorage API
